# Growth and Robux (plan, not promises)

No one can guarantee a game goes viral. What we can do is build the moments that get clipped and make the first minute easy.

## Built for clips
- The dawn reveal ("X was the saboteur") is the shareable moment: short, readable, ends every round.
- Round is 4 minutes: quick to retry, easy to record 15-30 s of.
- Later: spectator cam, kill-cam replay, emotes that show up well on video.

## Built for retention (later milestones)
- Daily shift streak, unlockable locker cosmetics, titles earned by roles ("Survived 10 nights").
- Friends invite flow + private servers (a Roblox-supported revenue source).

## Robux, only when the loop is fun (cosmetics, never power)
- Cosmetic game passes (flashlight skins, locker themes, name colours), emote packs.
- Private-server price, a "supporter" pass, limited seasonal cosmetics.
- Never sell roles, saboteur odds, tasks or anything affecting who wins.
- Engagement-based Premium payouts reward time played, so a smooth first minute matters most.

## Launch checklist
Icon + thumbnails (brand/), 3 screenshots, trailer cut from real clips, a clear description with keywords, enable favorites/like reminder in game, post clips daily (docs/MARKETING.md).
